# HTML, CSS, JS Assignment

Solutions for the HTML, CSS and JavaScript assignment: Array Manipulation, Object Manipulation,
Functions and DOM Manipulation (Q1–Q10 compulsory, Q11 bonus in each topic).

## How to run

Open `index.html` in a browser and click any question.

- **Array, Object and Function questions** are `.js` files. They open through `run.html`,
  which shows the `console.log()` output on the page. The output also appears in the browser
  console (F12). Questions that use `prompt()` ask for input when the page loads.
- **DOM questions** each have their own `.html` page and a `.js` file with the same name.
- `style.css` is the shared stylesheet for all pages.
